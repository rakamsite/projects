# خط مبنای عمومی سئو صفائی

## روش برداشت

- Sitemap عمومی Yoast
- WordPress REST API عمومی
- HTML صفحه اصلی، فروشگاه و آرشیو Mercedes
- جست‌وجوی نمونه عبارت‌های تجاری و مشاهده صفحات رقیب

## محدودیت خط مبنا

بدون Search Console نمی‌توان Impression، Click، CTR، Position، Query یا صفحات نزدیک صفحه اول را مشخص کرد. اعداد ترافیکی باید پس از راه‌اندازی ابزار اندازه‌گیری به این فایل افزوده شوند.
