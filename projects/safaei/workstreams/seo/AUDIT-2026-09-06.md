# ممیزی اولیه محتوایی سئو صفائی

- تاریخ: 06/09/2026
- محدوده: محتوای عمومی قابل مشاهده، Sitemap، محصولات، دسته‌ها و نمونه نتایج رقبا
- محدودیت: Search Console و Analytics در دسترس نیست؛ درباره رتبه، کلیک و نرخ تبدیل فعلی ادعایی نشده است.

## خلاصه مدیریتی

سایت موجودی بزرگی دارد اما معماری آن برندمحور است و برای تقاضاهای «قطعه + خودرو» صفحه هدفمند کافی ندارد. بنابراین گوگل تعداد زیادی صفحه محصول کم‌محتوا و آرشیو برند می‌بیند، نه یک مرجع ساختاریافته برای قطعات اکسور، آتگو و اکتروس.

## یافته‌های قطعی

- Sitemap شامل ۲۷۴۹ محصول و ۶۸ دسته محصول است.
- همه دسته‌های بررسی‌شده برندمحور هستند و هیچ‌کدام توضیح ثبت‌شده ندارند.
- عنوان صفحه اصلی «صفحه نخست - بازرگانی صفائی» است و در HTML بررسی‌شده H1 و Meta Description مشاهده نشد.
- فروشگاه و آرشیو Mercedes نیز H1 و Meta Description مناسب نداشتند.
- حدود ۲۰ محتوای اصلی سایت بیشتر پیرامون ثبت‌نام خودرو و خدمات پس از فروش هستند.
- صفحه و آرشیو آزمایشی `test` در مسیرهای قابل ایندکس دیده شد.
- نمونه صفحات محصول بررسی‌شده توضیح اصلی و Meta Description اختصاصی نداشتند.

## نتیجه راهبردی

مزیت صفائی باید ترکیب «محصول واقعی + کد فنی + خودرو و مدل سازگار + برند موجود + امکان استعلام عمده» باشد. مقاله عمومی بدون اتصال به این ساختار در اولویت نیست.
