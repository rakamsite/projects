- کانال‌های شناخته‌شده: سایت، اینستاگرام و کانال‌های پیام‌رسان

## تصمیم فعلی

در سئو، انتشار مقاله عمومی اولویت ندارد. ابتدا باید صفحات تجاری خودرو و زیرسیستم بر اساس محصولات واقعی ساخته شوند.

## موانع

- Search Console و خط مبنای کلیک، Impression و Query وجود ندارد.
- محصولات بر اساس برند دسته‌بندی شده‌اند و نگاشت قابل‌اتکای خودرو و زیرسیستم هنوز آماده نیست.
