# مرکز مدیریت پروژه‌ها

## تمرکز جاری

- ایجاد Search Console و ثبت خط مبنای قابل‌اندازه‌گیری قبل از ارزیابی رشد.
- اجرای Pilot نگاشت محصولات اکسور به خودرو و زیرسیستم.
- آماده‌سازی انتشار صفحه اکسور پس از تأیید داده Pilot.

## روش استفاده

1. وضعیت اجرایی هر پروژه را از `projects/<project>/README.md` بخوانید.
2. جزئیات هر حوزه مانند سئو یا تبلیغات داخل `workstreams/<area>/` همان پروژه نگهداری می‌شود.
3. کارهای آینده فقط در بخش برنامه و Backlog ثبت می‌شوند؛ کار تکمیل‌شده فقط همراه نتیجه و شاهد وارد لاگ می‌شود.
4. پس از هر تسک، README پروژه و در صورت اثرگذاری کلان، همین README نیز به‌روزرسانی می‌شود.

## ساختار

```text
projects/<project>/
├── README.md
├── workstreams/<area>/
│   ├── README.md
│   ├── ROADMAP.md
│   └── reports/
├── data/
└── decisions/
```

برای افزودن پروژه یا حوزه جدید، از فایل‌های داخل [`templates/`](templates/) استفاده شود.
